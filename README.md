# Instructional Design & Training Portfolio

A self-contained website: `index.html` plus an `assets/` folder. Open `index.html` directly in a browser to preview before publishing.

## Getting a shareable link (pick one)

**Netlify Drop (fastest, no account needed)**
1. Go to https://app.netlify.com/drop
2. Drag this whole folder onto the page.
3. You'll get a live URL in seconds.

**GitHub Pages**
1. Create a new public repo on GitHub.
2. Upload `index.html` and the `assets/` folder (keep the same structure — assets inside a folder next to index.html).
3. In the repo, go to Settings → Pages → set source to the main branch, root folder.
4. Your link will be `https://yourusername.github.io/repo-name/`.

**Vercel**
1. Go to https://vercel.com, sign in, and choose "Add New Project."
2. Drag and drop the folder, or connect it from GitHub.
3. Deploy — you'll get a live URL immediately.
